Git moves your work through 3 stages:

   your files          staging area         local repo          GitHub
  (working dir)  ──▶   ("the index")   ──▶  (committed)   ──▶   (pushed)
                git add              git commit          git push

- git add = "I want to include these changes in my next save"
- git commit = "save them as one snapshot, with a message"
- git push = "upload my saved snapshots to GitHub"
