Which exit rule actually pays
Same signals, same entries — only the exit differs. Sorted best to worst by expectancy, which is R per trade and the only number that decides whether a rule makes money.
Expectancy is the average R a rule returns per signal; PF is gross wins ÷ gross losses, so below 1.00 the losses were larger. The range is a 95% confidence interval on expectancy — the shaded bar with a tick at zero. When the bar crosses the tick, the rule has no measurable edge.
